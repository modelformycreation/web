# G. Venkata Shashank — Cybersecurity Portfolio

A polished, responsive single-page portfolio for **G. Venkata Shashank**, an offensive security practitioner focused on responsible disclosure, web application penetration testing, OWASP Top 10 testing, and Python security automation.

## What is included

- Dark cybersecurity-themed landing page
- Responsive navigation and mobile menu
- Hero section with key positioning and profile links
- Impact metrics for responsible disclosure achievements
- Sanitized security research case study
- Project cards linking to GitHub repositories
- Skills matrix, timeline, education, and credentials
- Contact section with mailto form
- Print-friendly résumé/PDF layout via the “Save résumé PDF” button
- SEO metadata, Open Graph card, favicon, and web manifest

## Files

- `index.html` — page content and structured data
- `styles.css` — full responsive design and print styles
- `script.js` — interactions, counters, GitHub metadata hydration, and contact form behavior
- `assets/favicon.svg` — custom GS mark
- `assets/og-card.svg` — social preview image
- `site.webmanifest` — basic web app metadata

## Run locally

Open `index.html` directly in a browser, or serve the directory with any static server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

This is a static site and can be deployed to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any standard static hosting provider.
